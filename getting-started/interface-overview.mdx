## Layout

The web app has three parts:

- **The left sidebar**, for moving around your workspace
- **The file browser** in the middle
- **The agent panel** on the right, which you open with **Agent** in the toolbar

## Left sidebar

From top to bottom:

- **Workspace switcher.** Click your workspace name to switch workspaces, or click **Create team workspace**.
- **Search.** Finds files and folders by name. Press `⌘P` (Mac) or `Ctrl+P` (Windows). You can filter by type and date.
- **Shared.** Files and folders others have shared with you.
- **Workflows.** Opens your [workflows](/workflows/overview).
- **Trash.** Deleted files, which you can restore.
- **Connected.** Your connected drives (Google Drive, OneDrive, SharePoint, Dropbox) that the agent can see. Click one to browse it. This section only appears once a drive is connected.
- **Recent.** Files you opened recently.
- **Feedback.** Send us feedback.
- **Settings.** Opens Settings. See [Settings](#settings) below.
- **Your account.** Your name, plan and email. Click it to open your profile.

## File browser

The toolbar above your files has:

- **New**, with **New File**, **New Folder**, **Upload** and **Import from Cloud**
- **List view** and **Grid view**
- Sort options

Each file has a **⋮** menu with **Open**, **Rename**, **Make a Copy**, **Move to**, **Share**, **Download**, **Export to Cloud**, **Details** and **Delete**. PDFs also have **Request Signature**.

Right-click the file browser for **Organize this folder (⌘K)**, **Create New File**, **Create New Folder**, **Upload Files** and **Import from Cloud**.

**Organize this folder** asks AI to file everything in the folder you're looking at into sensible subfolders, right away. It has its own monthly allowance, shown in **Settings** > **Usage**. For filing that happens automatically as files arrive, use a [workflow](/workflows/overview).

## Agent panel

Click **Agent** in the toolbar, or press `⌘J` (Mac) or `Ctrl+J` (Windows), to open the agent. It works on the folder or file you have open. See [The agent](/agent/overview).

## Settings

Settings opens as a window over the app, with tabs down the side. Which tabs you see depends on your role.

| Tab | What it's for |
|-----|---------------|
| **Profile** | Your account |
| **General** | Workspace name and details |
| **Members** | Invite people and set roles (team workspaces) |
| **Billing** | Plan, seats and payment (owner only) |
| **Usage** | Assistant tasks, workflow files, folder organizes and storage used |
| **Workflows** | A summary of workflows, with **Open workflows** |
| **Integrations** | Connect Gmail, Outlook, Slack, Teams, Google Drive, OneDrive, SharePoint and Dropbox |
| **Agent** | What the agent can see and remember, and (for owners and admins) whether it's on and its limits |
| **File Requests** | Create and track [file requests](/features/file-requests) |
| **Signatures** and **Signing Templates** | Track [signature requests](/features/e-sign) and reuse templates |
| **MCP** | The [MCP server](/integrations/mcp-server) URL for other AI tools |

Owners and admins also see **Auto Organization**, **Activity Log**, **Email Blocklist** and **Import History**. The owner of a team workspace also sees **Danger Zone**.

## Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘J` / `Ctrl+J` | Show or hide the agent |
| `⌘P` / `Ctrl+P` | Search files and folders |
| `⌘K` / `Ctrl+K` | Organize this folder |
| `⌘C`, `⌘X`, `⌘V` / `Ctrl+C`, `Ctrl+X`, `Ctrl+V` | Copy, cut and paste files |
| `⌘A` / `Ctrl+A` | Select all |
| `⌘`-click / `Ctrl`-click | Select several files |
