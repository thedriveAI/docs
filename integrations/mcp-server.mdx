## Overview

The Drive AI has an MCP (Model Context Protocol) server. With it, AI assistants such as Claude, ChatGPT and Cursor can work with the files in your workspace. They can browse, search and read your files, including connected Google Drive, OneDrive, SharePoint and Dropbox folders, make changes you can preview and undo, manage sharing, and hand bigger jobs to [the agent](/agent/overview).

## Server URL

```text
https://thedriveai.fastmcp.app/mcp
```

You can also find it in the app: open **Settings** and choose **MCP**.

## Connect an AI tool

<Tabs>
  <Tab title="Claude Desktop">
    1. Open **Settings** > **MCP** in The Drive AI, or go to [thedrive.ai/mcp](https://thedrive.ai/mcp).
    2. Click **Claude Desktop** to download the manifest.
    3. Open the downloaded file with Claude Desktop, then sign in to The Drive AI when prompted.
  </Tab>
  <Tab title="Claude.ai and ChatGPT">
    1. In Claude or ChatGPT, open the settings for connectors.
    2. Add a custom connector with the server URL above.
    3. Sign in to The Drive AI when prompted.
  </Tab>
  <Tab title="Cursor">
    1. Open **Settings** > **MCP** in The Drive AI, or go to [thedrive.ai/mcp](https://thedrive.ai/mcp).
    2. Click **Cursor** to install it in one click.
  </Tab>
  <Tab title="Command line">
    Run the command for your tool:

    <CodeGroup>
    ```bash Claude Code
    claude mcp add --scope local --transport http thedriveai https://thedriveai.fastmcp.app/mcp
    ```

    ```bash Codex CLI
    codex mcp add --url https://thedriveai.fastmcp.app/mcp thedriveai
    ```

    ```bash Gemini CLI
    gemini mcp add thedriveai https://thedriveai.fastmcp.app/mcp --transport http
    ```

    ```bash VS Code
    code --add-mcp '{"name":"thedriveai","type":"http","url":"https://thedriveai.fastmcp.app/mcp"}'
    ```
    </CodeGroup>
  </Tab>
  <Tab title="Other tools">
    Add the server URL to your tool's MCP configuration. For example:

    ```json
    {
      "servers": {
        "thedrive": {
          "url": "https://thedriveai.fastmcp.app/mcp"
        }
      }
    }
    ```

    Where this goes depends on the tool. Check its documentation.
  </Tab>
</Tabs>

## What connected tools can reach

A connected tool acts as you, with your permissions. It reaches the files in your workspaces, including the connected drives you can see in The Drive AI. Moves and copies stay within one drive, and sharing changes apply to files in The Drive AI, not to Google, Microsoft or Dropbox permissions.

Changes work the same way as with [the agent](/agent/overview#approving-and-undoing-changes):

- **Preview first.** The tool sees what a change would do before anything happens.
- **You confirm bigger changes.** Larger changes, moving files to the trash and sharing ask for your confirmation. A confirmation is valid for 15 minutes.
- **Undo.** An applied change can be undone, with the same [limits on connected drives](/agent/connected-drives#undo-on-each-drive). Deleting moves files to the trash, and editing a file keeps its earlier version.

When a tool hands a job to the agent, it counts as one of your [assistant tasks](/agent/overview#tasks-and-limits). Other tool calls don't count.

<Note>
  To connect, your The Drive AI account must sign in with Google. Accounts created with Microsoft, Apple or email can't connect yet.
</Note>

## Give the agent tools from other apps

This works the other way round. Owners and admins can connect other apps' MCP servers so the agent can use them. Open **Settings** > **Agent**, go to **What the agent can do elsewhere**, and click **Add MCP server**. The agent asks before it takes any action other than reading through those tools.
