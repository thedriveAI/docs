## Overview

A file request collects documents from clients, vendors or anyone else. Each recipient gets an email with their own upload link. They open the link, upload their files, and the files land in the folder you chose. Recipients don't need an account.

<Note>
  Creating file requests needs a plan that includes them. See [Plans & Pricing](/account/plans-pricing).
</Note>

## Where to find file requests

Open **Settings** and choose **File Requests**. It lists every request with its recipients, the files received, and its status.

## Create a request

<Steps>
  <Step title="Start a new request">
    In **Settings** > **File Requests**, click **New request**. The **Request files** form opens.
  </Step>
  <Step title="Fill in the details">
    - **Title**: required, for example "Q4 Tax Documents"
    - **Message to recipients**: optional instructions
    - **Recipients**: an email (required) and a name (optional) for each person. Click **Add recipient** to add more.
    - **Required documents**: optional checklist. Click **Add document** for each item. You can add helper text to an item, or choose **Use template** to load a saved checklist.
    - **Destination**: the folder uploads go to (**Workspace root** by default)
    - **Expires**: optional date after which the link stops working (**No expiry** by default)
  </Step>
  <Step title="Set more options (optional)">
    Open **More options** for:

    - **Rename uploaded files**: a naming pattern built from variables: **Original name** `{original_name}`, **Recipient** `{recipient_name}`, **Email** `{recipient_email}`, **Date** `{date}`, **Title** `{request_title}` and **Document name** `{slot_name}`
    - **Smart reminders**: reminds recipients who haven't uploaded yet, **Every day**, **Every 2 days**, **Every 3 days**, **Every 5 days** or **Weekly**
    - **Completion email**: emails you when a recipient has uploaded every required document on the checklist. Each upload also shows up in your in-app notifications.
    - **Save as template**: saves the checklist so you can reuse it (shown when the request has a checklist)
  </Step>
  <Step title="Send">
    Click **Send Request**. Each recipient gets an email with their link. The confirmation screen also lists every recipient's link with **Copy link**, so you can share the links yourself.
  </Step>
</Steps>

## What recipients see

Recipients open their link in a browser. They see your title, your message and the checklist, and they can drop files onto the page or browse for them. Each checklist item has its own **Upload** button, and **Replace** swaps a file they already uploaded.

Uploads only go through the link. If the link has expired or you've closed the request, the page says so.

## Track and manage a request

Open a request from **Settings** > **File Requests** to see:

- Each recipient's status: **Pending**, **In progress** or **Complete** (**Received** when there's no checklist)
- Each checklist item, marked as received, **Missing** or **Optional**

While a request is active you can:

- **Copy upload link** for a recipient
- **Send reminder** to a recipient who hasn't finished
- Add a recipient, or **Remove recipient**
- **Close request**, which stops further uploads
