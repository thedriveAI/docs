## Ask the agent

The [agent](/agent/overview) can work on PDFs for you. Open the folder with your PDFs, open the agent, and describe what you want:

```text
Merge all the PDF invoices in this folder into one document
```

```text
Split this contract into separate files, one per section
```

```text
Extract pages 5 to 10 into a new PDF
```

```text
Add a "CONFIDENTIAL" watermark to this PDF
```

```text
Fill out this W-9 with the details from my company profile document
```

```text
Compress this PDF so it's small enough to email
```

The agent can merge, split, rotate, reorder, extract pages, compress, watermark, password-protect and fill in PDF forms. It can also create new PDFs, such as a one-page summary of several contracts.

A new PDF appears in the chat as a file card. **View** or **Download** it, or choose **Save to a folder**. When the agent changes a PDF you already have, it asks first and keeps the previous version.

<Tip>
  To fill a form, point the agent at the document that has the information: "Fill in this form using the details in my profile document."
</Tip>

## Free browser tools

The Drive AI also has free PDF tools that run in your browser, with no account needed, at [thedrive.ai/tools](https://thedrive.ai/tools):

- Merge PDF, split PDF, compress PDF
- Rotate, reorder and delete PDF pages, add page numbers
- Add a watermark, sign a PDF
- Convert PDF to JPG, and JPG, PNG or other images to PDF
- Compress images
