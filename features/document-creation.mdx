## Overview

The [agent](/agent/overview) doesn't only manage files you have. It can also create new ones. Describe the document you need, and it writes it, often using your existing files as the source.

| Type | Formats |
|------|---------|
| **Documents** | PDF, Word (DOCX), text, Markdown |
| **Spreadsheets** | Excel (XLSX), CSV |
| **Presentations** | PowerPoint (PPTX) |

## Examples

```text
Summarize the contracts in this folder in a one-page PDF
```

```text
Make a spreadsheet of every invoice here with vendor, date and total
```

```text
Create a project tracker spreadsheet with columns for task, owner, status and due date
```

```text
Turn the Q3 report into a five-slide presentation
```

```text
Draft an NDA for freelance contractors as a Word document
```

The agent reads your files for the facts. For example, it can build a spreadsheet by reading every invoice in a folder.

## Getting the file

A new file appears in the chat as a file card:

- **View** it in place
- **Download** it (several files download together with **Download all**)
- **Save to a folder** to add it to your workspace or a connected drive

Until you save it, the file stays in the chat for 30 days. An owner or admin can switch on **Save the files it makes** in **Settings** > **Agent**, so the agent can save the files it makes into a folder without asking first.

To change a file after it's made, just ask: "Add a section on Q2 projections." When the agent edits a file that's already in your workspace, it asks first and keeps the previous version. On a connected drive, see [Undo on each drive](/agent/connected-drives#undo-on-each-drive).

## Tips

<AccordionGroup>
  <Accordion title="Say the format" icon="file">
    "Create a PDF report" gets you a PDF. "Create a report" leaves the choice to the agent.
  </Accordion>
  <Accordion title="Describe the structure" icon="list">
    "A spreadsheet with columns for Name, Email, Phone and Company" gives the agent a clear target.
  </Accordion>
  <Accordion title="Point at the sources" icon="link">
    Open the folder with the source files first, or name them: "Using the three vendor proposals, make a comparison table."
  </Accordion>
</AccordionGroup>
