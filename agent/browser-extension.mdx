## Overview

The Drive AI browser extension opens the agent in Chrome's side panel. It knows which Google Drive, OneDrive, SharePoint or Dropbox folder or file you're looking at, so you can say "this folder" or "these files" without explaining where they are.

It is the same agent as in the web app, with the same [approvals and undo](/agent/overview#approving-and-undoing-changes) and the same task limits.

## Install

1. Open [The Drive AI in the Chrome Web Store](https://chromewebstore.google.com/detail/the-drive-ai/dielhikhcaoicomkojmkaebadghicngm) and click **Add to Chrome**.
2. Pin the extension to your toolbar so it's easy to find.

The extension works in Google Chrome and other Chromium browsers that support side panels.

## Sign in

1. Click The Drive AI icon in the toolbar. The side panel opens.
2. Click **Sign in**. A tab opens where you sign in to The Drive AI.
3. When it says **Login Successful**, the tab closes and the side panel is ready.

If you belong to more than one workspace, pick one from the workspace menu at the top of the panel.

## Work with the page you're on

Open a folder or file in one of these, then ask the agent about it:

- Google Drive (drive.google.com) and Google Docs, Sheets and Slides
- OneDrive, personal or work
- SharePoint
- Dropbox
- The Drive AI web app

The chip next to the message box shows the name of the folder or file the agent treats as "here" or "this". On pages without a single folder or file, like search results or **Recent**, it shows the drive you're in, or **Workspace** when the extension can't tell which drive.

For the agent to act on a drive, that drive must be [connected](/agent/connected-drives) to your workspace. The extension only tells the agent where you are. It doesn't give the agent access.

## When the agent can't see the page

A note in the panel tells you why. While the panel is open, it checks again every 30 seconds:

| The note says | What to do |
|---------------|------------|
| "… isn't connected to this workspace, so the assistant can't see this page." | Click **Connect** and connect that drive. |
| "Connecting … comes with …" or "Connecting … isn't part of this workspace's plan." | Your plan doesn't include connected drives. Click **See plans**, or ask your workspace owner. |
| "The assistant hasn't reached this item in … yet." | The drive is still being catalogued. Try again shortly. |
| "This … is signed in to an account that isn't connected to this workspace…" | Connect that account, or switch to an account that's connected. |
| "More than one … account is connected, and this page doesn't say which one it's signed in to." | Show the page's account, for example by opening the account menu on the drive's site, and the extension picks it up. |
| "This item isn't in anything connected to this workspace, so the assistant can't see it." | The file is in someone else's drive, a shared drive that isn't added, or a shared drive your connected account can't open. Connect the account that owns it or is a member of the shared drive, or ask an admin to add the shared drive. |
| "The agent is not enabled for this workspace." | Ask a workspace owner or admin to turn it on in **Settings** > **Agent**. |

## Account menu

Click **⋮** at the top of the panel to open the **Account** menu. It shows:

- The email you're signed in with
- Your plan and how many assistant tasks you've used
- **Connected accounts**, which opens **Settings** > **Integrations** in the web app
- **Plans**
- **Theme**
- **Sign out**
